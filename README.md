# isargadikusuma.github.io

Personal portfolio website for Arga Dikusuma, built with Astro and deployed to GitHub Pages.

## Stack

- Astro
- Tailwind CSS 4
- GitHub Pages
- GitHub Actions

## Commands

```sh
npm install
npm run dev
npm run build
npm run preview
```

## Deployment

The site is deployed from `main` using `.github/workflows/deploy.yml`.

Production URL: `https://isargadikusuma.github.io`
